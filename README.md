# Skin_Lesion_Segmentation
Designed and implemented a deep learning-based system for automated skin lesion segmentation from dermoscopic images, leveraging both Convolutional Neural Networks (CNN) and Segmentation Adversarial Networks (SegAN). The CNN model was trained for pixel-wise binary classification, while the SegAN architecture integrated adversarial training with multi-scale L1 loss to enhance boundary precision and structural accuracy. The models were evaluated on the HAM10000 dataset, achieving high segmentation performance with Dice scores of 0.85 (CNN) and 0.89 (SegAN), and IoU scores of 0.78 and 0.82 respectively. The project demonstrates strong proficiency in medical image analysis, deep learning, and model evaluation metrics.
